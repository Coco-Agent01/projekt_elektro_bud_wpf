Opis problemu
Projekt Elektro-Bud Magazyn to aplikacja w WPF, która ułatwia wyszukiwanie produktów w magazynie. Pozwala szybko znaleźć produkt i sprawdzić jego podstawowe informacje.

Wymagania funkcjonalne
Wyświetlanie listy produktów.
Wyszukiwanie po nazwie lub kodzie EAN.
Filtrowanie wyników podczas wpisywania tekstu.
Wyświetlanie informacji o produktach w tabeli.

Wymagania niefunkcjonalne
Prosty i czytelny interfejs.
Szybkie wyszukiwanie produktów.
Łatwa obsługa aplikacji.
Czytelne przedstawienie danych.
